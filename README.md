## 🎮 About the Game

**Guess My Number!** is a fun, interactive browser game where players try to guess a secret random number between **1 and 20**.

* **Score System:** Players start with **20 points**. Each incorrect guess decreases the score by 1.
* **Dynamic Feedback:** Real-time messages give hints whether your guess is *"Too high!"* or *"Too low!"*.
* **Win State & High Score:** Guessing the correct number turns the screen green, reveals the secret number, and saves your session **High Score**.
* **Play Again:** The *"Again!"* button resets the secret number and current score without losing your highest score record.

## 💡 Key Concepts & Learnings

This project served as a practical application of core vanilla JavaScript fundamentals:

* **DOM Manipulation:** Selecting and modifying HTML elements, text content, inline CSS styles, and input values dynamically using `document.querySelector()`.
* **Event Handling:** Using `addEventListener()` to handle user interactions on click events (`Check!` and `Again!` buttons).
* **Game State Management:** Managing dynamic state variables for `score`, `highscore`, and `secretNumber`.
* **Conditional Logic:** Implementing game rules, win/loss conditions, and high-score tracking.
* **Refactoring & DRY Principle:** Writing clean, non-repetitive JavaScript logic.
